# 2. Création, retraits et annulation

La création vérifie les dates, le montant et le transfert initial. Un retrait met à jour le montant déjà encaissé et empêche de réclamer deux fois la même période. Selon le modèle, l’expéditeur peut annuler le flux et récupérer la part non acquise, tandis que le bénéficiaire conserve ce qui est déjà disponible.

Les opérations doivent aussi gérer les tokens non conformes et les arrondis de précision.
