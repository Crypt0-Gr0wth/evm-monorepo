# 1. Flux de paiement Sablier

Sablier représente un paiement étalé dans le temps par un flux on-chain. Le créateur dépose les fonds, définit un bénéficiaire et une période, puis le bénéficiaire peut retirer la portion devenue disponible. Le solde restant est calculé à partir du temps et du montant total.

Le monorepo regroupe plusieurs versions et produits ; les contrats EVM exposent des interfaces distinctes selon le type de flux.
