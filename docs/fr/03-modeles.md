# 3. Modèles de flux et extensions

Les modèles de Sablier couvrent des flux linéaires et des formes plus riches avec segments, cliff ou tranches. Une abstraction commune permet aux intégrateurs de retrouver le montant disponible, le montant restant et l’état du flux.

Les extensions de token, de permissions et de création groupée augmentent la puissance mais aussi le nombre d’hypothèses à documenter. Le code source distingue les interfaces, bibliothèques de calcul et contrats de règlement.
